# Bedrock Block Placement

A Minecraft (NeoForge / Fabric, 1.21.1) client-side mod by Niceninjapro that brings Bedrock Edition-like block placement and breaking to Java Edition:

- Fast, gap-free block placement while holding the use key
- Reach-around placement for quick bridging
- Fast block breaking in a straight line in creative mode

Everything is configurable in the mod's client config and can be toggled in-game with the "Toggle Fast Block Placement" key binding (unbound by default).

Requires [Puzzles Lib](https://www.curseforge.com/minecraft/mc-mods/puzzles-lib) (and Fabric API + Forge Config API Port on Fabric).
